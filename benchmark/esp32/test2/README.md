# ESP32 Benchmark Test2

Этот benchmark тестирует шесть одновременных процессов на ESP32:
1-5. **Задачи счётчиков**: пять отдельных задач, каждая инкрементирует свой счётчик на 1024 в цикле
6. **Задача мониторинга**: печатает значение аппаратного таймера и значения всех пяти счётчиков

Все задачи работают в рамках cooperative планировщика задач Martos.

## Структура

Программа содержит шесть задач, добавленных в cooperative планировщик задач:

- `counter1_task_*` - `counter5_task_*`: Функции для пяти задач счётчиков, каждая из которых инкрементирует свой AtomicU32 счётчик на 1024 в каждой итерации. Задачи останавливаются после достижения значения 100000.
- `monitor_task_*`: Функции для задачи мониторинга, которая получает и выводит значение аппаратного таймера ESP32 и все пять счётчиков одновременно. Задача работает бесконечно.

## Установка зависимостей

Для установки зависимостей для разработки приложений под архитектуру Xtensa ESP32,
см. [официальный сайт](https://docs.esp-rs.org/book/installation/riscv-and-xtensa.html).

Пример установки на Linux (Ubuntu/Debian):
```bash
apt-get -qq update
apt-get install -y -q build-essential curl
curl https://sh.rustup.rs -sSf | sh -s -- -y
cargo install espup
espup install
```

## Сборка

Установите переменные окружения ESP32:
```bash
. $HOME/export-esp.sh
```

Затем соберите проект:
```bash
cargo build --release
```

## Запуск

Для подробных инструкций по запуску проектов для ESP32 см. [официальный сайт](https://docs.esp-rs.org/book/tooling/espflash.html).

```bash
cargo run
```
